# **App Name**: ScoutSafe

## Core Features:

- Camp Project Import: Import camp project data including coordinates and details for map integration.
- Interactive Map Visualization: Integrate Google Maps or OpenStreetMap to visualize the camp area and display relevant environmental risk data.
- Environmental Risk Analysis: Leverage external APIs to analyze potential environmental hazards such as floods, earthquakes, and strong winds.
- Tent Stability Simulation: Simulate tent stability based on weight distribution, knot types, and wind resistance using provided parameters.
- Safety Report Generation: Generate customized safety reports and practical recommendations based on risk assessment. Exportable to PDF format.
- User Authentication: Implement user login and security measures using Firebase authentication to ensure secure access to the platform.
- Dynamic Recommendation Tool: An AI tool assesses the current simulation parameters and compares them to historical incident data, determining when to suggest practical recommendations.

## Style Guidelines:

- Primary color: Forest green (#386641) to reflect nature and safety.
- Background color: Light beige (#FAF7ED) for a calm and readable interface.
- Accent color: Terracotta (#BC6C25) for highlights and important actions.
- Body font: 'PT Sans', a humanist sans-serif, suitable for both headlines and body text.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use clear and concise icons to represent various data points and actions, ensuring accessibility and usability.
- Incorporate subtle animations for map interactions and data loading to improve user experience.
